STEP 1 — Add Pydantic models
================================================================================
File: backend/models.py  (NEW)
Mirror the frontend EventBundle shape EXACTLY. Key gotchas:
  - agency_score must be float (not str)
  - example_phrases must be a list of {text:str, type:str}
  - first_appeared_at is Optional[str] (nullable)
  - source is a Literal["wayback","live"] or str

  --- models.py (skeleton) ---
  from __future__ import annotations
  from typing import Literal, Optional
  from pydantic import BaseModel

  class OutletOut(BaseModel):
      id: str
      name: str
      url: str
      authority_tier: str

  class EventOut(BaseModel):
      id: str
      title: str
      summary: str
      first_reported_at: str

  class ArticleOut(BaseModel):
      id: str
      event_id: str
      outlet_id: str
      url: str
      headline: str
      published_at: str
      full_text: str

  class HeadlineSnapshotOut(BaseModel):
      id: str
      article_id: str
      headline_text: str
      captured_at: str
      source: Literal["wayback", "live"]

  class StakeholderOut(BaseModel):
      id: str
      event_id: str
      name: str
      role: str
      first_appeared_at: Optional[str] = None

  class SourceAttributionOut(BaseModel):
      article_id: str
      official_ratio: float
      independent_ratio: float

  class PhraseOut(BaseModel):
      text: str
      type: str

  class AgencyFramingOut(BaseModel):
      article_id: str
      agency_score: float
      example_phrases: list[PhraseOut] = []

  class LanguageIntensityOut(BaseModel):
      article_id: str
      emotional_score: float
      certainty_score: float
      urgency_score: float

  class CoverageMatrixOut(BaseModel):
      article_id: str
      stakeholder_id: str
      present: bool

  class SignalsBundleOut(BaseModel):
      source_attribution: list[SourceAttributionOut] = []
      agency_framing: list[AgencyFramingOut] = []
      language_intensity: list[LanguageIntensityOut] = []
      coverage_matrix: list[CoverageMatrixOut] = []

  class EventBundleOut(BaseModel):
      event: EventOut
      outlets: list[OutletOut] = []
      articles: list[ArticleOut] = []
      snapshots: list[HeadlineSnapshotOut] = []
      stakeholders: list[StakeholderOut] = []
      signals: SignalsBundleOut

  Verify:  python -c "from models import EventBundleOut; print('ok')"

STEP 2 — Add GET /events/{event_id}/bundle
================================================================================
File: backend/main.py  (EDIT — add a new endpoint; do NOT touch /analyze or /health)

Approach: reuse get_supabase_client(). Query each table with .select("*"),
assemble into EventBundleOut. Sort to match frontend:
  articles   -> order("published_at")
  snapshots  -> order("captured_at")
  stakeholders -> order("first_appeared_at")   (nullable sorts last; fine)
  example_phrases: supabase returns jsonb as a Python list/dict already — pass
    through after coercing each item to PhraseOut(text=..., type=...).

  --- paste into main.py (after /health) ---
  from models import EventBundleOut, SignalsBundleOut

  @app.get("/events/{event_id}/bundle", response_model=EventBundleOut)
  def get_event_bundle(event_id: str) -> EventBundleOut:
      client = get_supabase_client()

      ev = client.table("events").select("*").eq("id", event_id).maybe_single().execute()
      if not ev.data:
          from fastapi import HTTPException
          raise HTTPException(status_code=404, detail="Event not found")

      articles = client.table("articles").select("*").eq("event_id", event_id).order("published_at").execute()
      article_ids = [a["id"] for a in (articles.data or [])]
      outlet_ids = [a["outlet_id"] for a in (articles.data or [])]

      outlets = client.table("outlets").select("*").in_("id", outlet_ids).execute() if outlet_ids else type("R",(),{"data":[]})()
      snapshots = client.table("headline_snapshots").select("*").in_("article_id", article_ids).order("captured_at").execute() if article_ids else type("R",(),{"data":[]})()
      stakeholders = client.table("stakeholders").select("*").eq("event_id", event_id).order("first_appeared_at").execute()

      ssa = client.table("signals_source_attribution").select("*").in_("article_id", article_ids).execute() if article_ids else type("R",(),{"data":[]})()
      saf = client.table("signals_agency_framing").select("*").in_("article_id", article_ids).execute() if article_ids else type("R",(),{"data":[]})()
      sli = client.table("signals_language_intensity").select("*").in_("article_id", article_ids).execute() if article_ids else type("R",(),{"data":[]})()
      cov = client.table("coverage_matrix").select("*").in_("article_id", article_ids).execute() if article_ids else type("R",(),{"data":[]})()

      agency_framing = []
      for row in (saf.data or []):
          phrases = row.get("example_phrases") or []
          agency_framing.append({
              "article_id": row["article_id"],
              "agency_score": float(row["agency_score"]),
              "example_phrases": [{"text": p["text"], "type": p["type"]} for p in phrases],
          })

      signals = {
          "source_attribution": ssa.data or [],
          "agency_framing": agency_framing,
          "language_intensity": sli.data or [],
          "coverage_matrix": cov.data or [],
      }

      return EventBundleOut(
          event=ev.data,
          outlets=outlets.data or [],
          articles=articles.data or [],
          snapshots=snapshots.data or [],
          stakeholders=stakeholders.data or [],
          signals=signals,
      )

  (The `type("R",(),{"data":[]})()` trick is just an empty-result stub so the
   `.data` accesses below don't crash when article_ids is empty. Cleaner: use
   `client.table(...).select("*"); res = res.execute()` only inside `if article_ids`,
   else set the var to {"data": []}.)

STEP 3 — Frontend: add fetchEventBundleFromApi() (parallel, unused by default)

  export async function fetchEventBundleFromApi(eventId: string): Promise<EventBundle> {
    const res = await fetch(`/api/events/${eventId}/bundle`);
    if (!res.ok) throw new Error(`Backend API error: ${res.status}`);
    return res.json();
  }

  NOTE: URLs depend on the Vite proxy (Step 4). If you instead call the backend
  directly, use `http://localhost:8000/events/${eventId}/bundle`.
